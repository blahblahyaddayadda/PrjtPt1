# YogiTrack

YogiTrack is a web-based application for managing Yoga H’om studio records.

## Features

- Instructor and customer management
- Class and package management
- Package sales
- Class attendance
- Weekly class schedule
- Studio reports

## Technology

- React
- JavaScript
- CSS
- Browser local storage for the Part 1 prototype
